## KB Finance (QuickLoan) – Cross-Platform Finance App  

Developed a **cross-platform finance application with web dashboard** using **Flutter** for the frontend and **Firebase** for backend services.  

- Implemented **OAuth 2.0 Google Authentication** for secure login and user onboarding.  
- Integrated **Cloud Firestore** for user data management, loan requests, and real-time updates.  
- Enabled **secure document storage** (PDFs and images) with **get_storage** for local caching.  
- Utilized **Dio** for API calls and **shared_preferences** to support dual modes: *User* and *Banker*.  
- Designed an intuitive **dashboard** with loan application forms, request tracking, and instant status updates.
